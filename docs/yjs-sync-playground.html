Yjs sync playground

Two independent Y.Docs, no server. Edit each side, then hit sync and watch the actual bytes: a state vector first (tiny — what I already have), then a diff (only what I'm missing). Real yjs, loaded from a CDN, same version this repo pins in packages/app/package.json.

Module import failed. If you opened this as a bare file:// path, some browsers block module scripts fetching remote CDN URLs. Serve it locally instead, e.g. from the repo root: bunx serve docs, then open the printed localhost URL.
